# 2026-09-05

## 为 PDFMathTranslate-local 增加 MTranServer 翻译服务支持

工作区原本为空，从 https://github.com/jiangchuanso/PDFMathTranslate-local.git 克隆（含子模块
`pdf2zh/kernel/PDFMathTranslate-next.git` = PDFMathTranslate-next v2 内核）。

新增翻译器 `MTranServerTranslator`（`name = "mtranserver"`），对接 https://github.com/xxnuo/MTranServer：

- 接口：`POST {endpoint}/translate`，body `{from, to, text, html:false}` → 响应取 `result` 字段；
  认证 `Authorization: Bearer <token>`（服务端未设 `MT_API_TOKEN` 时不需要）。
- 语言码：服务端用 `NormalizeLanguageCode` 自行归一化，本地 `lang_map = {"zh": "zh-Hans", "zh-tw": "zh-Hant"}`。
- 长文本由服务端按句拆分（`translateLongText`），客户端无需分片；`html` 固定 false（pdf2zh 传入的是纯文本）。

注册点（新增一个翻译服务需要同步改这几处，顺序按现有风格插入 `ModelScope` 之后）：

1. `pdf2zh/translator.py`（类定义，追加在文件末尾最利于 upstream sync）
2. `pdf2zh/converter.py`（v1 内核的服务列表 + import）
3. `pdf2zh/pdf2zh.py`（`--babeldoc` 分支的 import 与列表）
4. `pdf2zh/gui.py`（import、`service_map`、`babeldoc_translate_file` 列表）
5. 文档：`docs/ADVANCED.md` + `docs/README_{zh-TW,ko-KR,ja-JP}.md` 服务表；`README.md` 与
   `docs/README_zh-CN.md` 的「Recent Updates」条目。

刻意未改动：

- `pdf2zh/kernel/v2_bridge.py`：`SERVICE_NAME_MAP` 只收录 v2（pdf2zh_next 子模块）真正支持的引擎，
  `minimax`/`openailiked`/`qwen-mt`/`302ai` 同样不在其中，故 MTranServer 也不加（v2 模式暂不支持）。
- `pdf2zh/kernel/PDFMathTranslate-next.git/`：子模块，不动。

验证方式（本机无项目依赖，在 `$env:TEMP` 建临时 venv，用完即删）：

- 需装 `requests peewee tenacity deepl ollama openai xinference-client azure-ai-translation-text
  tencentcloud-sdk-python-tmt pytest`。
- 坑：`tencentcloud-sdk-python-tmt` 最新版 3.1.129 的 `models.py` 已不含 `TextTranslateRequest`，
  `import pdf2zh.translator` 会 ImportError；降到 `3.0.1300` 可正常导入。
- `pytest test/test_translator.py` 14 passed（新增 5 个 MTranServer 用例）；另用本地 HTTP stub
  跑通真实请求流程后删除临时脚本。
- `gui.py` 的 2 条 flake8 告警（F401/F841）为改动前既有，非本次引入。
